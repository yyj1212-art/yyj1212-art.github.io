# SZ1 IRES Analysis Figures

Place the generated PNG figures from the SZ1 IRES mutation analysis in this directory.

Expected figures:

- `delta_mfe_distribution.png` — distribution of predicted ΔMFE values across single-nucleotide substitutions
- `delta_mfe_vs_structure_change.png` — relationship between ΔMFE and local structure change
- `mutation_structure_landscape.png` — mutation-level structure landscape
- `position_structure_landscape.png` — position-level structure landscape
- `structure_change_distribution.png` — distribution of structural changes

These figures are exploratory computational outputs and should be interpreted together with the experimental dataset and model-validation results.
