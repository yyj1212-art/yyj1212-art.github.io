# Structural analysis figures

These static figures summarize RNAfold-derived outputs across the single-substitution landscape:

- `delta_mfe_distribution.png`: distribution of ΔMFE values.
- `delta_mfe_vs_structure_change.png`: ΔMFE against local structure difference.
- `mutation_structure_landscape.png`: mutation-level structural landscape.
- `position_structure_landscape.png`: position-level summary.
- `structure_change_distribution.png`: distribution of local structure differences.

These are computational structure estimates. They do not predict experimental translation efficiency.
